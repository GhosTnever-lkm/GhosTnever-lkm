### Быстрый старт: CLI

```bash
# Проверить папку мода и сохранить оба отчёта
python -m pip install "modrelease-studio @ git+https://github.com/GhosTnever-lkm/modrelease-studio.git@v0.3.77"
modrelease scan ./my-mod --md-out report.md --json-out report.json

# Сравнить английскую и русскую локализации
python -m pip install "game-text-gate @ git+https://github.com/GhosTnever-lkm/game-text-gate.git@v0.1.15"
game-text-gate --source locales/en.json --target locales/ru.json --report markdown
```

### 🛡️ Качество и безопасность игровых модов

- **ModRelease Studio v0.3.77** — проверка папки или ZIP перед выпуском: упаковка, секреты, метаданные, сравнение сборок и отчёты без локальных родительских путей; разделители строк отображаются явно, текстовый файл, выросший сверх лимита во время чтения, получает предупреждение, в folder scan не следует symlink и Windows junction, а при недоступности метаданных junction каталог исключается и получает предупреждение `READ_METADATA`; generated-папки отсекаются до индексации и не занимают лимит; ZIP-скан проверяет каждый упакованный файл (включая `.git` и `node_modules`) на случайные секреты. Недоступные каталоги при обходе дают отдельную blocking-ошибку с путём; OS-junk отмечается предупреждением. [Сайт и демо](https://ghostnever-lkm.github.io/modrelease-studio/) · [релиз v0.3.77](https://github.com/GhosTnever-lkm/modrelease-studio/releases/tag/v0.3.77) · [скачать ZIP](https://github.com/GhosTnever-lkm/modrelease-studio/releases/download/v0.3.77/ModRelease-Studio-v0.3.77.zip) · [SHA-256](https://github.com/GhosTnever-lkm/modrelease-studio/releases/download/v0.3.77/ModRelease-Studio-v0.3.77.zip.sha256)
- **Mod Threat Lens v0.1.9** — локальная эвристическая проверка скриптов, бинарных файлов и ZIP-архивов. Это инструмент первичного анализа, а не антивирус и не вердикт о безопасности. [репозиторий](https://github.com/GhosTnever-lkm/mod-threat-lens) · [релиз](https://github.com/GhosTnever-lkm/mod-threat-lens/releases/tag/v0.1.9) · [скачать ZIP](https://github.com/GhosTnever-lkm/mod-threat-lens/releases/download/v0.1.9/mod-threat-lens-v0.1.9.zip)
- **AegisScan AV v0.1.1** — локальный triage-сканер файлов и ZIP-архивов: ограниченный обход, пользовательские SHA-256 сигнатуры, объяснимые эвристики и JSON/текстовые отчёты. Ничего не запускает, не загружает и не удаляет; не заменяет коммерческий антивирус. [репозиторий](https://github.com/GhosTnever-lkm/aegisscan-av) · [релиз v0.1.1](https://github.com/GhosTnever-lkm/aegisscan-av/releases/tag/v0.1.1)
